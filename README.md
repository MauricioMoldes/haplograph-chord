# HaploGraph web app

React 18 + Tailwind 3 + D3 7, built with Vite. Static: no backend. The page reads tiles written by `make_tiles.sh`
from `./data/` (nginx: `/data/`).

Views (hash routes): `#/` genome chord · `#/pair/6-21` block matrix · `#/pair/6-21/10-9` with the edge list ·
`#/chr/21` chromosome network (force layout or arcs by position).

## Develop

    npm install
    npm run dev:data      # synthetic tiles in public/data (same format as the real ones)
    npm run dev

To develop against real tiles, copy a few from the cluster into `public/data/` (`index.json`,
`chrpair_by_band.tsv`, and the `matrix/`, `edges/`, `network/` tiles you want). Missing tiles show a
"not available" message.

## Build and deploy

    npm run build         # dist/ (dev tiles are not included)
    git add dist && git commit

On gm-web01: `sh /opt/deploy/deploy_haplograph.sh`. It rsyncs `dist/` and leaves `/var/www/haplograph.haploblocks.org/data/` alone.

## Tiles on the server

    /var/www/haplograph.haploblocks.org/data/
      index.json  chrpair_by_band.tsv  matrix/  edges/  network/

nginx can serve the `.gz` copies make_tiles.sh writes: add `gzip_static on;` to the server block.

## Config

`src/config.js`: cohort line, filter line, and `locusUrl` (where a block links to; UCSC hg38 by default).

## Data files
`public/data/meta.json` (optional, not generated by the tile job) supplies the title, cohort text, filters text, genome build and citation shown in the header, footer and About page:
`{"title":"HaploGraph","cohort":"1000 Genomes, N = 2,548 individuals","n_individuals":2548,"filters":"lift ≥ 2, weight ≥ 5; clusters with min(support, N − support) ≥ 25","genome_build":"hg38"}`
Everything else shown (bands, bin size, top-K, edge totals) is read from `index.json`.
